2. Creating a Personal Website Using GitHub Pages

If you want to create a full portfolio website hosted on GitHub, use GitHub Pages. Here's how you can configure it:
Step 1: Enable GitHub Pages

Create a new repository (e.g., username.github.io).
Go to the repository settings.
Scroll to GitHub Pages and configure the branch to serve your website. Typically, it's the main branch.
Step 2: Add HTML/CSS Files

You can code your portfolio website using HTML, CSS, and JavaScript. Here's an example structure:

plaintext
username.github.io/
├── index.html
├── style.css
├── projects/
│   ├── project-1.html
│   ├── project-2.html
│   └── project-3.html
├── images/
│   ├── project-1-visualization.png
│   └── project-2-visualization.png
└── README.md
Step 3: Customize Your Website

html
